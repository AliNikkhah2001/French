# Overview

Version **interactive** du Devoir 1 du cahier de classe. Formats : **compléter** (fill), **QCM** (mc), **ordonner** (order). Travaillez sans regarder le PDF — les corrigés s’affichent après « Check my answers ».

# Grammar

## Dire l’heure

- **Il est** + heure · **à** + heure pour situer un événement
- **et quart** (:15) · **et demie** (:30) · **moins le quart** (:45)

## Dates & jours

- **le** + nombre + mois · **le premier** pour le 1er
- Suite : lundi → mardi → mercredi → jeudi → vendredi → samedi → dimanche
