# Overview

Format **order** + communication : remettez les dialogues dans l’ordre, puis choisissez la bonne réplique.

# Grammar

## Structure d’un RDV

1. Saluer (**Bonjour !**)
2. Demander un rendez-vous
3. Proposer un jour / une heure
4. Confirmer (**est-ce possible ?**)
5. Saluer (**Au revoir !**)
