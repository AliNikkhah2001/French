# Overview

Ce hub liste **uniquement des sources légales** pour accompagner Édito A1 (Didier 2022–2024).

- Nous **ne redistribuons pas** le livre, le cahier, ni les corrigés Didier.
- Les drills de ce parcours sont **originaux** (mêmes thèmes que le sommaire public).
- Pour les **corrigés officiels** : cahier papier/numérique ou guide pédagogique (compte prof).

# Grammar

## Comment travailler avec Édito + cette app

1. Ouvrez votre **livre / cahier** (papier + [didierfle.app](https://didierfle.app/) ou Educadhoc).
2. Faites la page de l’unité.
3. Revenez ici : flashcards + examen de l’unité companion.
4. Renforcez avec TV5MONDE / Everyday French (liens ci-dessous).

## Sommaire public (cahier)

U0 Bienvenue · U1 Je suis… · U2 Près de moi · U3 Qu’est-ce qu’on mange ? · U4 C’est où ? · U5 C’est tendance ! · U6 Qu’est-ce qu’on fait aujourd’hui ? · U7 Chez moi ! · U8 En forme ! · U9 Bonnes vacances ! · U10 Au travail !
