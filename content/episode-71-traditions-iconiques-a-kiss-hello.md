Dans l'Antiquité, les gens d'une même classe sociale se faisaient la bise. Les gens d'une classe sociale inférieure, eux, faisaient une bise sur les mains ou sur les pieds des gens d'une classe supérieure. |  |  |

| Dans les années 1970, dans les entreprises françaises, on commence à essayer de faire comme les Américains. Alors, c'est le début des open spaces. | Quand vous arrivez au bureau et que vous faites la bise à votre collègue, qui est votre meilleur ami, vous n'allez pas serrer la main de la personne à côté de lui. Cette personne pourrait se sentir mal à l'aise, alors il faut faire la bise à tout le monde. |  |  |

| Mes parents me disaient : « Mathieu, ce n'est pas très poli de ne pas faire la bise ». Ça fait aussi partie de l'éducation. Donc, quand on est enfant, on nous apprend à le faire quand même, qu'on aime ou qu'on n'aime pas. |  |  |
