# Overview

Présentez votre **famille** et choisissez le bon **adjectif possessif**. L’accord se fait avec le **nom possédé**, pas avec le possesseur.

# Grammar

## Tableau

| | masc. sing. | fém. sing. | pluriel |
|---|---|---|---|
| je | mon | ma | mes |
| tu | ton | ta | tes |
| il/elle | son | sa | ses |
| nous | notre | notre | nos |
| vous | votre | votre | vos |
| ils/elles | leur | leur | leurs |

Règles :
- *Elle aime **son** frère.* (frère = masculin)
- *Il aime **sa** sœur.* (sœur = féminin)
- Pluriel : *mes parents*, *ses clés*
