# Overview

Pratiquez ce que vous avez vu en classe : **l’heure**, **les dates**, **les jours de la semaine** et **les saisons**. Lisez la grammaire, apprenez le vocabulaire, puis faites l’examen.

# Grammar

## Dire l’heure

- **Il est** + heure. Ex. : *Il est sept heures.* · *Il est midi.* · *Il est minuit.*
- **et quart** = :15 · **et demie** = :30 · **moins le quart** = :45
- Pour situer un événement : **à** + heure → *Le cours commence **à** 9 heures.*

## Écrire une date

- Formule : **le** + nombre + mois → *le quatorze février*
- Le 1er du mois : **le premier** janvier (pas *le un*)

## Jours & saisons

- Suite : lundi → mardi → mercredi → jeudi → vendredi → samedi → dimanche
- Saisons : printemps · été · automne · hiver
