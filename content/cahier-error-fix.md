# Overview

Format **error-correction** : lisez la phrase incorrecte, tapez la version correcte.

# Grammar

## Erreurs fréquentes

- *rendez-vous **de** mardi* → **pour** mardi
- *je ne suis dispo **pas*** → *je ne suis **pas** dispo*
- *à le musée* → **au** musée
- *ma père* → **mon** père

# Vocabulary

| French | English | Type | Note |
|---|---|---|---|
| pour mardi | for Tuesday | expression | pas de |
| au musée | to the museum | expression | à + le |
| ne… pas | not | grammar |  |
